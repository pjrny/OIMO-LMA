6. Legal, Compliance & Cryptographic Protection

Operating under strict Texas privacy statutes (HB 1181, HB 581, CUBI Act) while utilizing C2PA headers and spatial steganography for deepfake protection.

⚖️ Texas CUBI & HB 1181

Zero-Retention Age Tokenization

To comply with Texas statutory penalties (up to $10,000/day for unverified access), neither the platform nor the third-party verifier stores ID images or biometric templates. Verifiers return a signed JWT stored in Cloudflare D1.

🔐 C2PA Cryptographic Signatures

Invisible Provenance Headers

Every unwatermarked image/video has an invisible C2PA JSON-LD manifest injected into its file header (EXIF/iTXt), signed with the platform's private cryptographic key to prove age-verified generation.

👁️ Spatial Fourier Steganography

Luminance Plane Fingerprinting

A high-frequency noise signal encoding the verified User ID is embedded across the image luminance plane. If a user strips header metadata or records a video, the watermark survives re-encoding.
